## n8n promotion config apply

Manage the apply direction config

### Synopsis

Manage the apply direction config of one promotion connection: the
branch 'apply' resets to and imports from. Use 'set' to replace it.

```
n8n promotion config apply [flags]
```

### Examples

```
  n8n promotion config apply set CONNECTION_ID --input apply.json
```

### Options

```
  -h, --help   help for apply
```
