## n8n project create

Create a project

### Synopsis

Create one team project with the given name, at most 255 characters. The
instance assigns the ID unless --id picks one (at most 36 characters; an ID
already in use is a 409). --description, --icon and --telemetry-tag set the
optional fields; after creation only the name can be changed, with
'n8n project update'.

The output is the created project, including the caller's role and scopes in
it. Older instances answer with no body; that is reported as created without
an ID, and 'n8n project list' recovers it. Quote names containing spaces. Add
members afterwards with 'n8n project user add'. Requires project:create and a
licensed instance.

```
n8n project create <name> [flags]
```

### Examples

```
  n8n project create "Billing automation"
  n8n project create Marketing --description "Workflows the marketing team owns" --icon emoji:📣
  n8n project create Ops --icon icon:server --icon-color "#ff6d5a" --telemetry-tag team=ops
  n8n project create Staging --id staging --output json
```

### Options

```
      --context string              saved context name to use (falls back to N8N_CONTEXT, then the saved current context; see 'n8n config context list')
      --description string          plain-text description, at most 512 characters (default: none)
  -h, --help                        help for create
      --icon string                 icon as emoji:EMOJI or icon:NAME, e.g. emoji:📣 or icon:server (default: none)
      --icon-color string           icon color, e.g. #ff6d5a; requires --icon (default: the instance's color)
      --id string                   project ID to use, at most 36 characters (default: generated by the instance)
      --output string               output format: text or json (JSON is the project object) (default "text")
      --telemetry-tag stringArray   custom telemetry tag as KEY=VALUE, repeatable (default: none)
      --url string                  instance URL override, e.g. https://n8n.example.com (falls back to N8N_URL, then the selected context URL)
```
