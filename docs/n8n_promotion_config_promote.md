## n8n promotion config promote

Manage the promote direction config

### Synopsis

Manage the promote direction config of one promotion connection: the
base branch promotions push to. Use 'set' to replace it.

```
n8n promotion config promote [flags]
```

### Examples

```
  n8n promotion config promote set CONNECTION_ID --input promote.json
```

### Options

```
  -h, --help   help for promote
```
