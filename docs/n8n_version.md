## n8n version

Print build information

### Synopsis

Print build information: version, commit, build date, toolchain, and platform.

Use this when reporting bugs or checking which release is installed.

```
n8n version [flags]
```

### Examples

```
  n8n version
```

### Options

```
  -h, --help   help for version
```
